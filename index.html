File Galaxy

Demo galaxy
Runs entirely in your browser locally: nothing is being sent over the network, no data is collected, and none of your files are being uploaded anywhere. Large drives may pause the app for some time before anything appears. If that happens, it's your browser scanning the file paths in order to create the visualization; it is not frozen. You can save the “mapped” data file of your drive or a folder, so you can load the generated galaxy instantly, instead of doing a full re-scan. Enjoy!
